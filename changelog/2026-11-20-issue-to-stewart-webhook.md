CI: a new issue now gets a small JSON summary (repository, number, title, URL, author; never the issue body) posted straight to the Grok Bot "New issue triage" routine webhook, with the key as a bearer token, so Michael's project steward ("Stewart") can triage it onto the Projects board. GitHub's own issue webhooks cannot send an Authorization header, which is why this runs as a workflow instead. It stays quiet (and green) until the `GROK_ISSUE_WEBHOOK_URL` and `GROK_ISSUE_WEBHOOK_KEY` repo secrets are set.
